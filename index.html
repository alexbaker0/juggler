This is Eric Graham's original robot.dat. Line 1 is the eye position, then [altitude, azimuth] in degrees and a lens factor. Each object is <r,g,b> type (x,y,z):radius, where type 0 = dull, 1 = shiny, 2 = mirror. n (x,y,z):r sweeps n spheres to a new point, which is how the limbs are built. Then the lamps, and five colours: two floor tiles, ambient light, and sky zenith and horizon. Z is up; the floor is z = 0.

In 1986 Eric Graham wrote a ray tracer for the Commodore Amiga and used it to make The Juggler, a short looping animation of a robot juggling mirrored balls. It became one of the most famous early computer graphics demos. Each frame reportedly took around an hour to render. This is his original engine (RT1.C) and scene file, ported to C on the PC with one bug fix to the reflection maths, then compiled to WebAssembly. The image is split across your processor cores and drawn line by line, as the Amiga did. At the default settings the result matches the native PC build pixel for pixel.
